# Website Cek Kelulusan

Website sederhana untuk tugas pemrograman menggunakan:
- HTML: struktur halaman, form, tombol, output
- CSS: warna, ukuran, layout, dan tampilan flowchart
- JavaScript: input, validasi, perhitungan/proses, dan if/else

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka foldernya di VS Code.
3. Buka `index.html` di browser.
4. Masukkan nilai 0-100.
5. Klik "Cek Nilai".

## Logika
Jika nilai >= 75 -> LULUS.
Jika nilai < 75 -> TIDAK LULUS.
